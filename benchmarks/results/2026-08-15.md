# Host benchmark: 2026-08-15

Host: AMD Ryzen 5 3450U with Radeon Vega Mobile Gfx, Linux amd64.

The Go measurements used Go 1.25.1 and `go test ./benchmarks -run '^$'
-bench '^BenchmarkParse/' -benchmem -count=3`. The Polyglot measurements used
commit `d5aa0d493c281398c9fdbc6febd3577f10ceac2f`, Rust 1.96.0, and
`cargo bench --profile dev --no-default-features --bench parsing
parsing_by_size -- --noplot` with debug info disabled.

The profile choice matters: Polyglot's optimized all-dialect benchmark build
was SIGKILLed by the host during compilation, and the optimized transpile
suite was not completed. These numbers are therefore a parser smoke baseline,
not a publication-quality speedup claim.

| Case | golyglot median | Polyglot median (dev) |
| --- | ---: | ---: |
| simple | 11.5 µs/op | 79.8 µs/op |
| medium | 69.8 µs/op | 465.7 µs/op |
| complex | 289.8 µs/op | 1.718 ms/op |

Run the reproducible commands in [the benchmark guide](../README.md). Use a
larger host and `POLYGLOT_BENCH_PROFILE=bench` before drawing performance
conclusions.
